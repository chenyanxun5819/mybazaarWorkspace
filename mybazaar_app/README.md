# mybazaar_app

MyBazaar 的 Flutter app（Android 優先），服務現場角色（merchant / cashier / teamLeader），與 web 版（[mybazaar20](https://github.com/chenyanxun5819/mybazaar20)）共用同一個 Firebase 專案。工作進度記錄在 `markdown/YYYY/MM月/YYYYMMDD/`，專案慣例見 [CLAUDE.md](CLAUDE.md)。
